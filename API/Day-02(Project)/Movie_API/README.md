
# 🎥 BrowseBox Office – Movie Search App 🍿

BrowseBox Office is a simple and interactive **Movie Search Web App** built using **HTML, Bootstrap, and JavaScript**.  
It allows users to search movies instantly and fetch real-time data from the **OMDb API** 🎬✨

---

## 🚀 Live Features

✅ Search movies by title  
✅ Fetch movie details using OMDb API  
✅ Display movie **Title, Poster & Genre**  
✅ Save last searched movie using **LocalStorage**  
✅ Responsive UI with **Bootstrap 5**  
✅ Clean & beginner-friendly JavaScript logic  

---

## ⚙️ How It Works

1️⃣ User enters a movie title  
2️⃣ App sends a request to **OMDb API**  
3️⃣ Movie details are fetched and displayed  
4️⃣ Last searched movie is saved in **LocalStorage**  
5️⃣ On refresh, last movie auto-loads 🎯
